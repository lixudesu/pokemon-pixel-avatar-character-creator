# Contribuindo

Obrigado pelo interesse em melhorar o criador de avatar.

Este projeto aceita contribuicoes como:

- novos assets de roupa, cabelo, acessorio, mochila ou variacoes de cor;
- sprites de frente, costas, andando, correndo e bike;
- ajustes de alinhamento entre os formatos;
- correcoes de bugs;
- melhorias de responsividade e experiencia mobile;
- melhorias na documentacao.

## Assets

Para facilitar a integracao, mantenha os novos arquivos no mesmo padrao de organizacao usado em `assets/`.

Sempre que possivel, envie o conjunto completo da peca:

- `front`
- `back`
- `walk`
- `run`
- `bike`

Se uma peca existir apenas em alguns formatos, tudo bem. O criador ja consegue ignorar a camada faltante e manter o restante do avatar funcionando.

## Como enviar

Abra uma issue explicando a ideia ou envie um pull request com as mudancas.

Inclua, quando possivel:

- quais arquivos foram adicionados ou alterados;
- quais categorias/pecas foram afetadas;
- prints ou exemplos do avatar usando os assets novos.
